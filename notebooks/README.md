# Notebook

The entire project is contained in one notebook.
Run it end to end in Google Colab with a T4 GPU.

## How to Run
1. Click the Colab badge below
2. Enable GPU: Runtime → Change runtime type → T4 GPU
3. Run all cells from top to bottom
4. Each task is clearly labeled with section headers

## Sections
| Section | Description |
|---------|-------------|
| Task 1 | Dataset loading & exploration |
| Task 2 | Text preprocessing & CLIP embeddings |
| Task 3 | Conditional GAN from scratch |
| Task 4 | Attention-enhanced GAN |
| Task 5 | Fine-tune Stable Diffusion (LoRA) |
| Task 6 | Full end-to-end pipeline |
| Extra  | Gradio UI & evaluation |

## Requirements
- Google Colab with T4 GPU
- Hugging Face account and API token
  (get free token at huggingface.co/settings/tokens)
